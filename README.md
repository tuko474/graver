# Мастерская наград — демо магазина с 3D-конструктором

Сайт: https://tuko474.github.io/graver/

- `index.html` — главная и каталог
- `product.html?p=<id>` — страница изделия со встроенным 3D-конструктором (брусок, кристалл, звезда, волна, капля, стела)
- `library.html` — библиотека символов для гравировки: вложенные разделы, поиск, панель управления (разделы, загрузка, перенос картинок), перенос символа в конструктор (`product.html?p=<id>&sym=<id>`)
- `symbols.js` — разделы и стартовый набор символов библиотеки
- `catalog.js` — список изделий и начальные настройки конструктора
- `site.css` — общие стили, `img/` — фото изделий

Чистый HTML/CSS/JS, three.js r128. Цены, сроки и контакты условные.
