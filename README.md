# Конструктор наград

Демо 3D-конструктора наградной продукции из акрила и стекла: брусок 50×100×25 мм с гравировкой по граням (лицо, бока, верх, зеркальное дно), дополнительные формы, загрузка логотипа и расчёт стоимости с учётом тиража.

Смотреть: https://tuko474.github.io/graver/

Цены и формы в демо условные.
